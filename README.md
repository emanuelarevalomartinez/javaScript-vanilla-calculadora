# Calculator App

**Basic web calculator for performing arithmetic operations with chained expressions and decimal support.**

Calculator App is a lightweight web application built with pure HTML, CSS, and JavaScript that allows users to perform essential arithmetic operations through a simple and interactive interface.

## 📌 Description

This project is a basic calculator application designed to execute fundamental mathematical operations while reinforcing core frontend development concepts.

The application allows users to:

✔ Perform addition, subtraction, multiplication, and division

✔ Work with decimal numbers

✔ Chain multiple operations in a single calculation flow

✔ Reuse previous results for new calculations

✔ Clear all input and restart calculations

The project focuses on implementing calculation logic and interface interaction without relying on frameworks or external libraries.

---

## ✨ Main Features

* ➕ Addition support

* ➖ Subtraction support

* ✖ Multiplication support

* ➗ Division support

* 🔢 Decimal number input

* 🔄 Chained arithmetic operations

* 🟰 Explicit result evaluation (`=`)

* 🧹 Full reset functionality (`C`)

* 🎯 Interactive button-based input system

---

## 🧠 How It Works

The calculator follows a simple operational flow:

1. Input numbers
2. Select arithmetic operators
3. Build chained expressions
4. Execute calculation by pressing `=`
5. Continue operating with the resulting value or reset using `C`

The internal logic handles:

* Expression building

* Decimal validation

* Operator sequencing

* Result rendering

* State reset management
